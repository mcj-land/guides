---
title: "Core layer"
description: "Shared contracts and infrastructure components that every agent reuses."
---

Location: `src/core/`.

## `llm_fabric/`

LLM clients and a factory that creates and configures model connections.

## `memory_fabric/`

Conversation memory and history providers.

## `prompt_manager/`

Loads prompts from their sources.

## `tool_manager/`

Registry of the tools that agents can call.

## `interfaces/`

| Interface | Contract for |
|---|---|
| `BaseRuntime` | Running agents (`invoke()`, `stream()`) |
| `BaseLLMClient` | LLM clients |
| `BasePromptClient` | Prompt sources |
| `BaseTool` | Tools |

## `observability.py`

Tracing, metrics and telemetry.
