Location: `src/agent/`.

This layer decouples agent execution from the rest of the infrastructure, so you can add agents without touching the API.

## `agent/container.py`

The dependency injection composition root. It builds the LLM clients, memory providers, prompt sources, tools and configuration, and wires them into the runtime and agents.

## `agent/maf_runtime.py`

`MAFRuntime` implements `BaseRuntime` and runs agents. All adapters go through `BaseRuntime.invoke()` or `BaseRuntime.stream()`.

## `agents/`

One package per specialized agent. The archetype ships with samples:

| Agent | Purpose |
|---|---|
| `weather` | Weather queries |
| `telco` | Telecom queries |
| spam detector | Spam detection |
| `email_assistant` | Email assistant |

## `workflows/`

Workflows coordinate several agents or operations. Sample: `sample_spam_workflow_agent`.

## `prompts/`

Versioned system prompts used by the agents.
