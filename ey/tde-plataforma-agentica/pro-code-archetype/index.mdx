The archetype is a FastAPI service that runs agents through a common runtime. Every new agent reuses the same API, runtime and shared services instead of building its own stack.

## Layers

| Layer | Location | Responsibility |
|---|---|---|
| [API](/ey/tde-plataforma-agentica/pro-code-archetype/api-layer) | `src/main.py`, `src/api/` | FastAPI, middleware, routes, request normalization, DTOs |
| [Agent](/ey/tde-plataforma-agentica/pro-code-archetype/agent-layer) | `src/agent/` | Runtime (`MAFRuntime`), agents, workflows, prompts, dependency injection |
| [Core](/ey/tde-plataforma-agentica/pro-code-archetype/core-layer) | `src/core/` | Interfaces, shared infrastructure components, observability |
| [Periphery](/ey/tde-plataforma-agentica/pro-code-archetype/periphery-layer) | `src/tools/`, `src/config/`, `src/utils/` | Tools, configuration, utilities |
