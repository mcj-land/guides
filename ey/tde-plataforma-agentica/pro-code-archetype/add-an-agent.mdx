---
title: "Add a new agent"
description: "Where each piece of a new agent goes in the archetype."
---

<Steps>
  <Step title="Write the prompt">
    Add a versioned system prompt in `src/agent/prompts/`. `prompt_manager/` loads it at runtime.
  </Step>
  <Step title="Add tools">
    Implement each tool against `BaseTool` in `src/tools/`, as a local tool or an MCP server. Register it in `tool_manager/`.
  </Step>
  <Step title="Create the agent">
    Add a package in `src/agent/agents/`. Get the LLM client from `llm_fabric/` and history from `memory_fabric/`.
  </Step>
  <Step title="Wire it in the container">
    Register the agent and its dependencies in `src/agent/container.py`.
  </Step>
  <Step title="Expose the agent card">
    Describe the agent with `agent_card_utils` so it appears in the `agent_card/` endpoint.
  </Step>
  <Step title="Call it">
    Send a request to `responses/` or `stream/`. The API routes it through `MAFRuntime`.
  </Step>
</Steps>

To combine several agents, add a workflow in `src/agent/workflows/`.
