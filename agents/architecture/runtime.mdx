---
title: "Runtime"
description: "Runs agents behind one interface, whatever framework they use."
---

The runtime is the contract between the API and the agents. The API calls `invoke()` or `stream()` and never knows which framework the agent uses.

```python
class AgentRuntime(Protocol):
    async def invoke(self, request: AgentRequest) -> AgentResponse: ...
    def stream(self, request: AgentRequest) -> AsyncIterator[AgentEvent]: ...
```

## What it does

- Finds the agent for the request.
- Loads the conversation state.
- Runs the [agent loop](/agents/architecture/agent-loop) with its limits.
- Saves the new state and returns the result.

## Dependency injection

Build the model clients, memory stores, tools and settings in one place, the composition root, and pass them in. Agents ask for what they need instead of creating it. This makes it easy to swap an implementation and to test an agent with fakes.

## Framework choice

Frameworks such as LangGraph, Microsoft Agent Framework or the OpenAI and Anthropic agent SDKs all implement some version of this loop. Wrapping them behind your own runtime interface lets you change or mix frameworks later.
