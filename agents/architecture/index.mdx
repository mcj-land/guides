An agent is an LLM in a loop: it reads the request, decides what to do, calls tools, looks at the results and repeats until it can answer. The architecture exists to run that loop reliably for many users, and to make each new agent cheap to add.

## Four layers

| Layer | Job | Changes when |
|---|---|---|
| [API](/agents/architecture/api-layer) | Receives HTTP requests, validates them and hands them to the runtime | You add an endpoint or a client |
| [Agent](/agents/architecture/agent-layer) | Business logic: the runtime, the agents, workflows and prompts | You add or change an agent |
| [Core](/agents/architecture/core-layer) | Shared contracts and services: models, memory, prompts, tools, observability | You change a provider or a shared capability |
| [Periphery](/agents/architecture/periphery-layer) | Tool implementations, configuration and utilities | You integrate a new system |

Dependencies point inwards. The API depends on the runtime interface, agents depend on Core interfaces, and Periphery implements those interfaces. Nothing in Core knows about a specific agent.

## Project layout

```text
src/
├── main.py                  # Creates the app and middleware
├── api/
│   ├── router.py            # Registers routes
│   ├── endpoints/           # invoke, stream, health, agent_card
│   ├── request_handler.py   # Normalizes requests, sets the trace ID
│   └── schemas/             # Request and response models
├── agent/
│   ├── container.py         # Composition root: builds and wires everything
│   ├── runtime.py           # Implements AgentRuntime
│   ├── agents/              # One package per agent
│   ├── workflows/           # Multi-step and multi-agent flows
│   └── prompts/             # Versioned prompts
├── core/
│   ├── interfaces/          # AgentRuntime, LLMClient, MemoryStore, PromptSource, Tool
│   ├── llm/                 # Model gateway: clients and factory
│   ├── memory/              # Conversation history providers
│   ├── prompt_manager/      # Loads prompts from their sources
│   ├── tool_registry/       # Registers tools and gives each agent its own
│   └── observability.py     # Tracing, metrics, telemetry
├── tools/                   # Local tools and MCP clients
├── config/
│   ├── settings.py          # App settings from the environment
│   └── identity.py          # Credentials and identity
└── utils/
tests/
```
