---
title: "Design principles"
description: "The rules the archetype is built on."
---

| Principle | What it means |
|---|---|
| Single runtime entry point | Every adapter uses `BaseRuntime.invoke()` or `BaseRuntime.stream()`. |
| Framework-agnostic core | The API depends only on the `BaseRuntime` contract, not on the agent framework. |
| Dependency injection | All infrastructure is configured in `src/agent/container.py`. |
| Interface boundaries | Contracts in `src/core/interfaces/` decouple implementations and make testing easier. |
| Extensible and replaceable | Add LLM providers, agents or tools without changing the API. |
| Observability | Tracing, metrics and telemetry across the platform. |
| Reuse | Shared Core components so each agent doesn't rebuild the same features. |
